# Jornada do Treinador Pokémon · 75 LAB

Apresentação estratégica **HTML** — Análise de potencial em PDV para Pokémon.
Diagnóstico, oportunidades e plano de soluções de trade experience.

**75 LAB × The Pokémon Company International**

## Ver a apresentação
Acesse o link do GitHub Pages (publicado a partir deste repositório) ou abra `index.html` no navegador.

### Navegação
- `←` / `→` · setas do teclado ou botões na tela
- `F` · tela cheia
- Clique nos pontos inferiores para pular entre slides
- Funciona em desktop e mobile (swipe)

## Estrutura
- `index.html` — deck completo (20 slides, autocontido)
- `assets/fotos/` — evidências visuais de campo (PDVs reais)

## Espaço reservado

das peças de comunicação assim que forem enviados.
